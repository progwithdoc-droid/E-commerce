# AURUM STORE

A luxury fashion/lifestyle e-commerce landing page built with Next.js 14, TypeScript, Tailwind CSS, and Framer Motion.

## Features

- **8 Premium Sections**: Hero, Categories, Product Drop, Product Grid, Lookbook, Trust Strip, Testimonials, Newsletter, Footer
- **Smooth Scroll**: Lenis integration for buttery scroll experience
- **Custom Cursor**: mix-blend-mode cursor with hover states
- **Cart System**: Zustand-powered cart with slide-out drawer
- **Framer Motion**: Scroll reveals, parallax, stagger animations
- **Responsive**: Mobile-first design with breakpoints

## Tech Stack

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- Zustand
- Lenis
- Lucide React

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view the site.
